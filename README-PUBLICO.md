# Banco de hooks

Banco de ganchos para Reels em português do Brasil, com mais de 400 modelos separados por categoria, a prova de cada um (criador, views e envios na data da coleta), o checklist de auditoria, o filtro anti-texto-de-IA e o personagem do diretor criativo (Dante) que usa o banco.

Comece pelo `README.md` e pelo `SKILL.md`. Os dados estão em `data/`.
